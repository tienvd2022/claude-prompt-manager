                  Cài đặt Git
                  
      
      
      
      
                  Bật thì vào dự án hay đổi nhánh là tự đồng bộ luôn: pull về (xung đột thì mở phiên Claude xử lý ngay, dự án khóa tới khi xong), có commit mới là push. Không bao giờ tự commit. Vẫn tắt được riêng từng lần trong panel Git.
                  
      
                  
        Tài khoản git (SSH) của server
        
                  Đọc từ ~/.ssh/config: mỗi alias một key riêng, clone/push bằng git@<alias>:user/repo.git là ra đúng tài khoản. Copy public key, add vào GitHub → Settings → SSH keys của tài khoản đó.
                  
        
                    
        
                    
          
          
          
          
        
                    
        
                    Thêm alias: tạo key ed25519 mới và thêm khối Host vào ~/.ssh/config (config cũ sao lưu ở config.cpm-backup, không đụng key có sẵn). Sửa/xóa alias cũng sao lưu như vậy; xóa alias không xóa file key.
